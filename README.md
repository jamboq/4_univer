# Склад светового оборудования театра

Веб-приложение для управления складом светового оборудования театра (Служба постановочного освещения - СПО).

## Возможности

### 🎭 Управление оборудованием
- **Категории и подкатегории**: Световое оборудование, Электробутафория, Дым машины, Мастерская
- **Подкатегории**: Статические/Динамические приборы, 220v/3-24v
- **Характеристики**: Состояние, место хранения, спектакль, количество, инвентарный номер, статус
- **CRUD операции**: Добавление, редактирование, удаление, перемещение оборудования

### 🔍 Поиск и фильтрация
- Поиск по названию, описанию, инвентарному номеру
- Фильтрация по категориям, статусу, состоянию
- Сортировка по различным параметрам
- Поиск по спектаклям

### 👥 Система пользователей
- Регистрация и аутентификация
- Роли пользователей: Администратор, Менеджер, Пользователь, Наблюдатель
- Контроль доступа к функциям
- История действий пользователей

### 📊 Отчеты и статистика
- Статистика по оборудованию
- История перемещений и изменений
- Последние действия на главной странице
- Экспорт данных в CSV/JSON

### 🎨 Интерфейс
- Минималистичный дизайн
- Адаптивная верстка
- Интуитивно понятный интерфейс
- Поддержка темной темы (планируется)

## Использование

### Первый запуск
1. Запустите приложение
2. **Автоматический вход**: Приложение автоматически войдет в систему как admin в демо-режиме
3. **Ручной вход**: Если нужно войти вручную:
   - **Логин**: admin
   - **Пароль**: admin123

### Добавление оборудования
1. Перейдите в раздел "Оборудование"
2. Нажмите "Добавить оборудование"
3. Заполните форму:
   - Название (обязательно)
   - Категория (обязательно)
   - Состояние (обязательно)
   - Статус (обязательно)
   - Место хранения (обязательно)
   - Количество (обязательно)
   - Остальные поля по необходимости

### Управление категориями
1. Перейдите в раздел "Категории"
2. Нажмите "Добавить категорию"
3. Выберите родительскую категорию (если нужна подкатегория)

### Поиск оборудования
- Используйте поисковую строку в шапке
- Применяйте фильтры в разделе "Оборудование"
- Ищите по спектаклям, местам хранения

## API

### Оборудование
- `GET /api/equipment` - Получить список оборудования
- `POST /api/equipment` - Создать оборудование
- `PUT /api/equipment/:id` - Обновить оборудование
- `DELETE /api/equipment/:id` - Удалить оборудование
- `POST /api/equipment/:id/move` - Переместить оборудование

### Пользователи
- `POST /api/users/login` - Вход в систему
- `POST /api/users/register` - Регистрация
- `GET /api/users/me` - Получить текущего пользователя

### Категории
- `GET /api/categories` - Получить список категорий
- `POST /api/categories` - Создать категорию
- `PUT /api/categories/:id` - Обновить категорию
- `DELETE /api/categories/:id` - Удалить категорию

### История
- `GET /api/history` - Получить историю действий
- `GET /api/history/recent` - Получить последние действия

## База данных

Приложение использует SQLite для хранения данных. База данных создается автоматически при первом запуске.

### Таблицы
- `users` - Пользователи системы
- `categories` - Категории оборудования
- `equipment` - Оборудование
- `history` - История действий
- `movements` - Перемещения оборудования
